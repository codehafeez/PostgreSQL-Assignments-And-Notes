# PostgreSQL Assignments and Notes

A beginner-friendly collection of PostgreSQL assignments, practical examples, explanations, and study notes.

## 📘 Repository Content

* PostgreSQL fundamentals
* Database and table creation
* PostgreSQL data types
* Primary and foreign keys
* Database relationships
* INSERT, SELECT, UPDATE, and DELETE queries
* WHERE conditions and operators
* Sorting and filtering
* Aggregate functions
* GROUP BY and HAVING
* SQL joins
* Subqueries
* Common Table Expressions (CTEs)
* JSONB queries
* Views and indexes
* Transactions
* PostgreSQL UPSERT
* Practical assignments with explanations

## 📄 Assignment Document

[View or download PostgreSQL Assignment and Notes](./PostgreSQL_Assignment_and_Notes.pdf)

## 🛠️ Requirements

You can practise the examples using:

* PostgreSQL Server
* pgAdmin
* SQL Shell (`psql`)
* Visual Studio Code
* Any PostgreSQL-compatible online editor

## 🚀 How to Use

1. Open or download the PDF document.
2. Read the explanation for each topic.
3. Run the provided PostgreSQL queries.
4. Compare your results with the expected output.
5. Complete the practice assignments independently.
