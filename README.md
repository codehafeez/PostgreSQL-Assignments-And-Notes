# MySQL Assignments and Notes

A beginner-friendly collection of MySQL assignments, practical examples, explanations, and study notes.

## 📘 Repository Content

* MySQL fundamentals
* Database and table creation
* Data types
* Primary and foreign keys
* INSERT, SELECT, UPDATE, and DELETE queries
* WHERE conditions and operators
* Sorting and filtering
* Aggregate functions
* GROUP BY and HAVING
* Table relationships
* SQL joins
* Subqueries
* Views, indexes, and stored procedures
* Practical assignments with examples and outputs

## 📄 Assignment Document

[View or download MySQL Assignment and Notes](./MySQL_Assignment_and_Notes.pdf)

## 🛠️ Requirements

You can practise the examples using:

* MySQL Server
* MySQL Workbench
* XAMPP with phpMyAdmin
* Visual Studio Code
* Any MySQL-compatible online editor

## 🚀 How to Use

1. Open or download the PDF document.
2. Read the explanation for each topic.
3. Run the provided SQL queries.
4. Compare your results with the expected output.
5. Complete the practice assignments independently.
